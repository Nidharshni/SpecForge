Problem

The field type that declares a value has no single reading, so the Graph Protocol carries the parser's AST and a project that checks clean exports documents its own published schema rejects.

Solution

One module turns a declared type into the values it admits and the JSON it writes. E061, coercion, the writer and the published per-kind fragment all read that module.

Wins

  • Locality: one wire rule
  • Delete the 280-line hand-written schema
  • Tests validate an export against the published schema
  • Builtins' declarations stop lying
ADR 0034 settles the field type's name only; no ADR covers the admitted shapes. Needs a decision first: is formal's requires/ensures an edge list, as declared, or a block, as its pass reads it?

Solution

Top recommendation

1 · A declared field type decides one wire form

The Graph Protocol is SpecForge's main output, and today it breaks its own published contract: 1091 errors on this repo, with check reporting none. Extensions receive the parser's AST. Making one module own type → admitted value → JSON fixes E061, the writer and the published schema together, and makes "export validates against schema --publish" a single test. It first needs one domain decision: what formal's requires is.

If you want the hot spot first, take card 2: two live bugs, and the reason extension/ keeps churning. For the smallest contained fix, take card 3: delete one pass-through.
