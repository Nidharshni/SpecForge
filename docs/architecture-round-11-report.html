Breaking changes

  • MCP: a comma string in init's extensions, a local extension or write that resolves outside the served project (symlinks and .. included) is refused as invalid_input (outside_root). A rename preview over an escaping symlink is no longer refused, since the check moved into apply and nothing is written.
  • MCP replies: E059 is the operation's own message; the R-TRUST-003 suggestion text changes; tool results and resource reads carry I016, W053 and I020 in _meta.diagnostics.
  • CLI: init --extensions takes a list through clap and resolves .. the way the file system does; add names a missing relative file by its joined path; the read commands print I016 and W053 on stderr.
  • LSP: no spurious E002 through a symlinked directory; hover shows the last compile's coverage while the project rebuilds; fewer {dir}/* watchers.
  • Rust API: Containment is a required field of every request that reads or writes files; AddRequest.extensions is Vec<String>; Trust and Consent become Asking; ProjectView::new, begin_open, replaced, into_buffers, Environment::discover, RegistryBuild::files and Rules::files are gone; RuleInput gains disk.

Not in this PR

  • A registry operation's outcome carrying registry.reported() (W140, I003, W155, W156): ADR 0044 D5 decided it, and the friction is small.
  • The versioned-schema memo: ADR 0015 D2 stands, and a call costs about 4 ms.
  • Routing the environment's module reads (Installed::load) through the checks' disk: no drift today.
  • About 20 CLI analyze tests that assert only the document belong in ops (ADR 0029 D9a).
