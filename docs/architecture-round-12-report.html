Before and after, plan by plan

Decisions that changed an earlier round

  • 07-U1: every file_exists rule suggests a close sibling, so a missing path's directory is a listing read again. This reverses ADR 0107 D5(2)'s outcome (round 11's 04-U2); a file created beside a missing path re-runs the checks.
  • 06-U2: E022 sits on the reference token, not the whole entity (ADR 0093 D9). Its edge is kept for a wrong-kind reference.
  • 09-U1: under --format json a note for a person is written under human output only; a notice is written once, in the document when it has a field for it, else on stderr. This reconciles ADR 0029 D3a, 0052 D8 and 0111 D2.
  • 04, 03, 05: ADR 0019 "Placement", ADR 0107's rejected option and ADR 0016 D1's parenthesis are reopened, each with its reason in the new ADR.

Breaking changes

  • MCP: analyze test_results outside the project is invalid_input; collect and migrate refuse files that leave the project through a symlink; manifest readers return E071 for a manifest linked outside; rename is bounded by the project root and over a file changed since the compile is conflict; outline of a non-source is file_not_found; infer_* counts and listings change (no symlinked directory entered).
  • CLI: under --format json stderr loses analyze's W097, check's notes, search's R005, explore's I020 and migrate's rollback lines (stdout unchanged); review on an unreadable report exits 1, not 2; watch follows link targets and reacts to a retargeted link; infer-status and check --lint inferred give E071 for an outside-linked manifest.
  • Diagnostics (CLI, MCP, LSP): E022 moves to the token, gains a suggestion and is reported earlier; I004 names the extension; E016 fires on bare words and comes after the rules; E028 wording changes.
  • LSP: the watchers list each link and its targets, with no glob for a module the load did not read; the directory watcher for a missing file_exists path returns.
  • Rust API: Held, Containment::read and a required containment on collect, analyze's named report and the inference session; Navigator<'a> without text_of; specforge_project::snapshot moves to specforge-registry; Installed::read(root, disk), load takes a disk and Installed::modules is gone; absent_reference_targets becomes target_owners, EntityRecord.references and DerivedReference.target_kind are deleted; CandidateVocabulary replaces the registry's bundled JSON; CompiledProject::project_root() is gone; walk_files in specforge-common.

Not in this PR

  • The recorded test report is read through a symlink in the session layer (session/project/src/coverage.rs), below where Containment lives.
  • An extension command's graph export drops I016 and W053 (a gap in ADR 0111 D1's list); no user-visible effect was reproduced.
  • From round 11: a registry operation's outcome carrying registry.reported() (ADR 0044 D5), and about 20 CLI analyze tests that belong in ops (ADR 0029 D9a).
  • 09's one-shot read runner, if it is ever wanted (R1–R3 are sketched in the plan).
